The funniest sign for the door of a haunted server room: **"WARNING: This server room is haunted. The ghost has root access and has never filed a single ticket."** The program writes that one line to `/output/entry.txt` — a warning sign where the haunting is an IT problem: the ghost has root and has never once filed a ticket. Pure Python stdlib, deterministic, no network.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
